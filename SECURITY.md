# Security Policy

## Supported Versions

Only the latest version of Mergington High School's website will receive security updates.

| Version | Supported          |
| ------- | ------------------ |
| Latest  | :white_check_mark: |

## Reporting a Vulnerability

If you discover a security vulnerability within the Mergington High School website, please follow these steps to report it:

1. **Do not** open a public issue — report it to the site administrator.
2. Send an issue report to the **site administrator** of the Mergington High School website.
3. The administrator will respond within 24 hours, and if the issue is confirmed as a vulnerability, they will release a patch to the latest version within a reasonable time frame.

## Disclosure Policy

The Mergington High School website is built by students participating in the GitHub Skills courses. The GitHub security team might have access to vulnerabilities reported on the repository and could inform GitHub Skills to take action if necessary. At this time there is no official disclosure process for the Mergington High School website.
